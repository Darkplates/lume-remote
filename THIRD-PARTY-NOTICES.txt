SOURCE AVAILABILITY AND REBUILD
The complete source for each component is available at the repository and
exact revision above, including the pinned recursive submodules. The Lume source
package includes the two patches, their before/after hash manifest, and the
stdlib-only scripts/prepare-peer-source.py overlay preparer. Run BUILD-P2P.bat
to retrieve and validate those revisions, prepare the verified patched source
overlay without modifying the upstream checkout, and rebuild the DLL. Windows,
Android, Linux and Apple peer builders use that same source overlay procedure.
This developer-only rebuild requires Git, Python, Visual Studio C++ Build
Tools and a Windows SDK. It downloads a SHA-256-verified portable CMake into
the local build folder; it does not install a system runtime or service.

PUBLIC STUN SERVICE
The P2P mode uses stun:stun.cloudflare.com:3478 for address discovery.
STUN carries connectivity metadata, not desktop frames or input. No TURN
credentials or automatic relayed fallback are included. See:
https://developers.cloudflare.com/realtime/turn/

PUBLIC SIGNALING SERVICE (0.3)
Saved access uses wss://0.peerjs.com/peerjs for authenticated encrypted
coordination. Desktop data remains direct P2P. The provider sees random IDs,
network addresses, timing and encrypted envelope sizes. Availability and
provider policy are external dependencies, without a Lume service guarantee.
No PeerJS browser library is bundled. The native protocol adapter is original
Lume C# code. Documentation: https://peerjs.com/client/faq and
https://peerjs.com/server/cloud

WINDOWS MEDIA FOUNDATION
LumeVideo.dll is an original bridge to Windows-provided Media Foundation APIs.
Windows supplies the H.264 encoder/decoder implementations; Lume does not bundle
an additional H.264 codec runtime. Encoder availability depends on Windows,
hardware and drivers. File size or an FPS target does not establish performance.

PORTABLE PLATFORM SOURCE (0.8 DEVELOPMENT)
ports/Cargo.lock pins the Rust workspace dependency versions/checksums. When
portable binaries are packaged, third-party/portable/inventory.json records
the upstream license declarations and copied notice files from the corresponding
downloaded crates. Run scripts/collect-portable-notices.py after fetching the
locked workspace. Its optional --fetch-upstream mode reads missing root notices
from the exact GitHub commit recorded in the checksum-verified published crate.
Font notices are retained separately. Every copied notice has a checksum and
crate-relative path or exact upstream URL. Missing notices remain explicit gaps;
the generated inventory is not an independent licence or security review.

Android packages also contain the Android NDK libc++ shared runtime. Its upstream
Apache 2.0 with LLVM exception notice must accompany a distributed APK. Android
and Apple applications link platform APIs supplied by their operating systems.
The Windows no-NuGet/no-extra-runtime requirement is unchanged by these separate
native platform projects.
