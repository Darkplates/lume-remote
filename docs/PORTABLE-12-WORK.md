# Portable collaboration and publication work

Scope: authenticated single-file resume using protocol 4 operations 12–16;
portable viewer annotation controls using tool 7; explicit local PDF printing;
upstream license provenance and an honest public development repository.

Keep existing guest and legacy file operations. Folder jobs remain session-only.
Resume must bind the paired key, canonical destination, name, length and complete
digest; verify retained prefixes before sending suffixes. Cancellation and integrity
failure discard the active partial. No resume keys appear in state or logs.

Annotation input is bounded and tied to the displayed generation; drawing releases
held input and must never inject mouse clicks. PDF printing uses verified downloads
and explicit local print selection, never remote commands or automatic execution.

Validation: interruption/retry, wrong identity, corruption, cancel, legacy transfer,
annotation bounds/generation, native PDF adapters, existing Windows safe checks,
portable core/ABI checks and platform builds. Physical WAN, printers, mobile devices,
and macOS/iOS remain separately reported. No Apple hardware is available.

Publication: source and curated evidence only, with no credentials, local databases,
raw desktop captures, private machine paths or unsupported parity claims. Preserve
the 0.11 archives and the installed Windows host.
