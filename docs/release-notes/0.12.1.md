Unsigned Windows development preview. Check the SHA-256 files and the producing workflow run before use.

## Security

Fixes [GHSA-hp7w-v83m-qgx8](https://github.com/Darkplates/lume-remote/security/advisories/GHSA-hp7w-v83m-qgx8) in the optional permanent-access Windows service.

**If you enabled permanent access with an earlier version:** extract this ZIP into a new folder, open `START.bat`, then choose **Settings → Update installed host** and approve the Windows prompt. The update applies the new folder permissions and service.

## Fixes

- Remote guests can no longer answer local permission prompts (voice, system audio, clipboard) with their own input. Incoming chat no longer takes keyboard focus.
- Saved-computer reconnection is no longer stopped by malformed signaling messages.
- Image regions draw correctly between PCs with different display scaling; H.264 works at widths such as 1366.
- Paired resumable transfers survive stalls; finished recordings are never deleted on a name collision.
- Display scaling at 125–200 % and a more complete dark theme.
- Confirmations for Forget and Remove Windows service, and clearer consent wording.

See [CHANGELOG.md](https://github.com/Darkplates/lume-remote/blob/main/CHANGELOG.md) for the full list.

## Known limits

Two-PC Internet acceptance, display scaling above 100 % and physical audio devices have not been verified for this preview. It does not claim a security audit, signed binaries or measured performance against other products.
