LINKEDIN
------------------------------------------------------------------------------
My first open-source project is public: Lume Remote, a small native remote desktop
app for Windows.

The idea is simple. You pair your own PCs once, then connect with one click. Guests
get a one-time invitation that you approve on your screen. There is no account, no
subscription and no session timer, and the application source is MIT licensed.

What I'm proud of in 0.12.1:
- Exact SHA-256 certificate pinning and fresh secrets for every session.
- Permanent access is opt-in, can be revoked at once, and shows a visible
  "connected" pill with a Disconnect button on the controlled PC.
- A security issue found in review was fixed and disclosed through a public GitHub
  advisory before this release.
- A new light and dark interface that follows your Windows setting.

It is an unsigned development preview, not a finished product. I'm looking for a
few Windows testers with two PCs and for people who enjoy security reviews.
https://github.com/Darkplates/lume-remote

Title: I made an open-source remote desktop for your own Windows PCs (no account, no session timer)

Body:
Hi all. Lume Remote is a small native Windows app for reaching your own computers.
Pair two PCs once with a one-time code, then connect from a saved list with one
click. Guests can join with a one-time invitation that you approve locally.

- No account, subscription, telemetry or session-duration cap.
- Pinned TLS (exact SHA-256) and a fresh session secret per connection.
- Files and folders both ways with SHA-256 verification and resume for paired PCs,
  clipboard text, chat, quality presets (lossless, H.264, low bandwidth), recording.
- Permanent access is opt-in, revocable, and shows a visible indicator while someone
  is connected.

Honest limits: it's an unsigned 0.12.1 development preview. Linux and mobile ports
are partial, macOS/iOS are untested (I don't have Apple hardware), and I haven't
published performance comparisons with other tools because I haven't measured them.

Feedback, bug reports and security reviews are very welcome:
https://github.com/Darkplates/lume-remote

HACKER NEWS (Show HN)
------------------------------------------------------------------------------
Title: Show HN: Lume Remote – open-source remote desktop for your own Windows PCs

Text:
Lume is a native Windows remote desktop (C#/.NET Framework, no runtime installs)
for connecting to machines you own. You pair PCs once and connect from a saved
list; guests use a one-time invitation that must be approved on the host.

A few design choices: exact SHA-256 pinning instead of a CA, a fresh session
secret per connection, authorization before any capture or input, bounded parsers
and queues, and an opt-in Windows service whose settings the SYSTEM service alone
writes (owner changes go through an authenticated named pipe). An earlier layout
of that service allowed local privilege escalation; it was fixed and disclosed in
GHSA-hp7w-v83m-qgx8.

It's a 0.12.1 development preview: unsigned, Windows-first, with partial Linux and
Android ports. I'd love feedback on the protocol and the permanent-access model.
https://github.com/Darkplates/lume-remote
