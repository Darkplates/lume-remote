# Reporting security issues

Please avoid publishing working secrets, pairing codes or access to another person's computer.

For a potential authorization, encryption or parser vulnerability, use GitHub's private vulnerability reporting if the repository maintainer has enabled it. Otherwise open a minimal issue asking for a private reporting channel, without exploit details or credentials.

This preview has not received an independent security audit. Read [the security boundaries](docs/SECURITY.md) before granting permanent access. Revoke a paired device immediately if its credentials may be compromised.
